# Third-party fonts and icons

All files here are self-hosted (no CDN). They were taken from npm packages with `npm pack --ignore-scripts`
(package scripts never run); only the Latin `.woff2` subsets and licence files were copied.

| Files | Source package | Licence |
|---|---|---|
| `newsreader-latin-{400,500}-normal.woff2`, `newsreader-latin-400-italic.woff2` | `@fontsource/newsreader@5.3.0` (Newsreader, Production Type) | SIL OFL 1.1 — `LICENSE-newsreader.txt` |
| `plus-jakarta-sans-latin-{400,500,600}-normal.woff2` | `@fontsource/plus-jakarta-sans@5.3.0` (Plus Jakarta Sans, Tokotype) | SIL OFL 1.1 — `LICENSE-plus-jakarta-sans.txt` |
| `jetbrains-mono-latin-{400,500}-normal.woff2` | `@fontsource/jetbrains-mono@5.3.0` (JetBrains Mono) | SIL OFL 1.1 — `LICENSE-jetbrains-mono.txt` |
| SVG path data in `js/icons.js` | `@material-symbols/svg-400@0.49.0`, outlined variant (Material Symbols, Google) | Apache 2.0 — `LICENSE-material-symbols.txt` |
